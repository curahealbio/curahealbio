## 제품 소개

**제로제로체크**는 (주)큐라힐바이오가 만든 **휴대용 당 검사지(스트립 타입)** 입니다.
검사지를 음료에 적시면 5~10초 안에 색 변화로 당이 들어 있는지 알려줍니다.

| | |
|---|---|
| 🟦 **색 변화 없음** | 당이 없는 제로 음료 |
| 🟫 **황갈색으로 변함** | 당이 들어 있는 음료 |
| 📦 **구성** | 1통 100회분 |
| 👜 **휴대성** | 가방·주머니에 들어가는 소형 디자인 |

카페 키오스크 주문 실수, 매장 제조 실수, 비슷한 포장 때문에 제로 음료 대신 일반 음료를 마시게 되는 일을 막아줍니다.
